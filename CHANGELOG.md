# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-07-30

### Added

- Separate persistent effort presets for Anthropic/Claude and OpenAI/GPT model families.
- Automatic preset application on session start and model changes.
- `/effort` selector, direct arguments, aliases, and command completion.
- Footer status showing the active model family's effective effort.
- Compatibility with the existing `~/.pi/agent/effort-presets.json` state file.
